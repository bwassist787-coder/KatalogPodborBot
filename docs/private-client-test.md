# Проверка интерфейса личного бота (тестовый режим)

Все новые клиентские заявки оформляются **только в личных сообщениях** с @KatalogPodborBot.
Клиентская группа остаётся местом обычной переписки и может содержать кнопки перехода в бота.

## Основные кнопки

- **Новая заявка** → «Описать своими словами» либо «Подобрать по фильтрам».
- **Мои заявки** → активные / завершённые, статусы, ответственный, подробности и вопрос менеджеру.
- **Предложить компанию** → существующая форма предложения, предложение не попадает в каталог без проверки.

Кнопки в клиентской группе — ссылки на приватный диалог. Старые групповые формы `gf:*` не принимают заявки и предлагают переход в личку.

## Привязка клиента

Только тестовая группа, точно указанная в Render через TEST_CLIENT_CHAT_ID, включена в клиентский маршрут. Бот проверяет пользователя через `get_chat_member` и сохраняет `client_group_id` в каждой новой заявке.

Фильтр «Мои заявки» проверяет одновременно `Telegram user ID` и `client_group_id`; другой клиент не видит запросы других аккаунтов. Сообщения менеджеров клиенту отправляются в личный чат.

Если в дальнейшем будет две и более клиентские группы, нельзя расширять маршрутизацию по совпадению названий. Прежде необходимо реализовать явные привязки Telegram user ID ↔ Chat ID с подтверждением разрешённости доступа и ручной проверкой конфликтов.

## Тестовые действия

1. Участник тестовой группы открывает личку бота и нажимает `/start`.
2. «Новая заявка» → «Описать своими словами» → тестовый текст → подтверждение.
3. Проверить заявку во внутреннем менеджерском чате.
4. Менеджер «Взять в работу», клиент видит статус через «Мои заявки».
5. Проверить «Новая заявка» → подбор по фильтрам.
6. Проверить «Предложить компанию».
7. Попробовать открыть чужую заявку по callback: действие должно блокироваться.
8. При необходимости повторно запустить `/setup_topics` в General и закрепить новые переходы в приватного бота.

**Только тестовые данные**: база SQLite на Render Free не постоянная, а проверка ЗСК для реальных компаний не автоматизирована.
