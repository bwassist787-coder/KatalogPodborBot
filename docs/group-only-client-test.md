# Актуальный тестовый интерфейс клиента — только Telegram-группа

## Работа клиента

- **General:** кнопки «Подобрать компанию», «Предложить компанию», «Мои заявки».
- **Предложения от Нас** (Topic ID 3): категория → пять компаний (название, ИНН, клиентская цена %, срок) → выбор №1–5 / «Ещё компании» / «Нужен менеджер» → подтверждение. Не требуется вводить ИНН клиента, сумму или НДС перед выдачей.
- **Предложения от Клиента** (Topic ID 2): отдельная форма в той же теме, где клиент предлагает свою компанию; принятие в каталог только после проверки.
- **Мои заявки:** заявки этого Telegram пользователя из текущей тестовой группы, со статусом и ответственным.
- **Личный чат с ботом:** только сообщение с инструкцией открыть клиентскую группу. Там не принимаются заявки, подборы и предложения.

## Безопасность

- Только точная тестовая группа с ID из TEST_CLIENT_CHAT_ID. Темы из TEST_CLIENT_TOPIC_OUT_ID / TEST_CLIENT_TOPIC_IN_ID.
- При нажатии кнопок проверяем членство в группе; состояние формы привязано к группе, теме, пользователю и токену.
- Обновляем карточку в клиентской теме и во внутреннем менеджерском чате.
- Менеджер отправляет ответы только в исходную подтверждённую тему. Старые личные маршруты заблокированы и требуют ручной проверки.
- Подтверждение формы защищено от повторной отправки.
- Строка «Цена» содержит только клиентскую цену из вкладки «Каталог_бот», не внутренние условия.
- Тестовые SQLite данные на бесплатном Render не долговечны. Реальные компании и клиенты пока не допускаются.

## Активация обновлённых кнопок

Старые Telegram сообщения с URL-ссылками в личку НЕ редактируются автоматически.
**Оператор:** открыть General в тестовой группе и один раз отправить /setup_topics.
Бот создаст новые меню во всех трёх темах. Проверить в каждом меню, что при нажатии
открывается новое сообщение в теме, а НЕ личный чат. Затем закрепить новые сообщения,
открепить и удалить старые кнопки-ссылки.

Тест: General → Подобрать компанию → Строительство → Выбрать №1 → Подтвердить →
проверить карточку в теме 3 и внутреннем менеджерском чате → Взять в работу →
проверить синхронизацию статусов.
