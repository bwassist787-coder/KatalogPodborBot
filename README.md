# Каталог-бот — @KatalogPodborBot

Тестовая версия Telegram-бота подбора предложений из Google Sheets. **Пока не запускать с реальными компаниями.**

## Возможности

- Команда /start показывает кнопки «По направлению», «По условиям», «Не нашёл нужное»; кнопки создаются кодом, а не BotFather.
- По направлению: 9 категорий → подкатегория → до трёх предложений на страницу.
- По условиям: НДС → сумма → предложения. Нет точных совпадений → близкие категории или запрос менеджеру.
- Заявка: ИНН клиента → сумма → комментарий → подтверждение; перед сохранением статус предложения перепроверяется.
- В тестовом режиме заявки сохраняются **локально в SQLite**, не во вкладке «Заявки». При наличии MANAGER_CHAT_ID уведомления уходят в отдельную группу.
- В тестовом режиме доступ разрешён только Telegram ID из ALLOWED_USER_IDS.
- Бот читает только вкладку «Каталог_бот» (клиентские поля). Прямой доступ клиентов к таблице не нужен.

## Как запустить на Railway

1. Перейдите на https://railway.com и выберите New Project → Deploy from GitHub repo → bwassist787-coder/KatalogPodborBot.
2. В сервисе откройте Variables и задайте следующие переменные:
   - BOT_TOKEN — секретный токен от BotFather. Храните только в Railway, никогда в GitHub или чате.
   - TEST_MODE = true
   - SHEET_ID = 1MnLci1DvDgHsahZfW4CQt_QqiN_uuaoidXaX9of-5rc
   - CATALOG_GID = 1884118558
   - ALLOWED_USER_IDS — ваш Telegram ID. Узнайте его командой /whoami после первого запуска; несколько ID разделяйте запятыми.
   - MANAGER_CHAT_ID — необязательно в первой проверке; Telegram ID закрытой группы менеджеров.
3. Примените изменения через Deploy. В railway.toml уже задан запуск: python bot.py. Для Telegram polling домен не нужен.
4. Откройте @KatalogPodborBot, отправьте /whoami, внесите полученный ID в ALLOWED_USER_IDS, примените обновление и отправьте /start.
5. Проверьте три кнопки меню. Не запускайте одновременно две копии бота с одним Telegram-токеном.

Важно: Railway может потерять локальный SQLite при повторном развёртывании. Поэтому тестовые заявки не считаются надёжно сохранёнными.

## Как добавить тестовое предложение

Откройте вкладку «Предложения» и заполните строку 2:

- A: DEMO-001
- B: ТЕСТОВАЯ КОМПАНИЯ 001
- C: текстовый ИНН 0000000000 (ставьте начальный апостроф перед нулями, чтобы сохранить все цифры)
- D: Транспорт и логистика
- E: Грузоперевозки
- F: Тестовая перевозка груза
- G: С НДС
- H: 100000
- I: 1000000
- J: 10%
- L: 3
- M: Только демонстрация
- O: Зелёный (тестовая имитация проверки)
- P: сегодняшняя дата
- Q: Да

K (Клиент %) и R (В каталоге) не изменять — формулы. Результат: K = 11,5%, R = Да. Затем тестовая карточка появится в «Каталог_бот».

## Безопасность и рабочий запуск

Тестовая версия загружает открытый CSV-экспорт вкладки «Каталог_бот». Держать **реальные** данные в публичной Google-таблице нельзя.

Перед рабочим запуском: закрыть таблицу, отделить клиентскую витрину от внутренней базы; настроить Google service account и права доступа. Ключ сервисного аккаунта хранить в секретах Railway (GOOGLE_SERVICE_ACCOUNT_JSON). После настройки допустим TEST_MODE=false; потребуется MANAGER_CHAT_ID. В этом режиме бот читает «Каталог_бот» и добавляет заявки во вкладку «Заявки».

Google Sheets не обеспечивает отдельную изоляцию прав по вкладкам. Автоматическая независимая проверка ЗСК и полный контроль уведомлений менеджерам пока НЕ реализованы. До этого использование реальных компаний не согласовано.
